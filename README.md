> Exploration de \*\*1 460 transactions\*\* — KPIs, visualisations interactives et storytelling de données.  

> Dataset : \[Kaggle House Prices - Advanced Regression Techniques](https://www.kaggle.com/c/house-prices-advanced-regression-techniques)



\---



\## 🎯 Objectifs du projet



\- \*\*Nettoyer\*\* un dataset brut (81 colonnes, 7 800+ valeurs manquantes) avec Pandas/NumPy

\- \*\*Modéliser\*\* les données dans PostgreSQL avec un schéma en étoile (dimension + fait)

\- \*\*Créer\*\* des KPIs métier pertinents pour l'analyse immobilière

\- \*\*Visualiser\*\* les insights via un dashboard Streamlit interactif

\- \*\*Raconter\*\* une histoire : quels facteurs influencent le prix d'une maison ?



\---



\## 🔍 Insights clés



| Insight | Détail |

|---------|--------|

| 💰 \*\*Prix moyen\*\* | 180 921 $ (médiane : 163 000 $) |

| 📐 \*\*Prix au sqft\*\* | 70 $ / sqft en moyenne |

| 🏘️ \*\*Écart quartiers\*\* | De 145 847 $ (NAmes) à 335 295 $ (NoRidge), soit \*\*×2,3\*\* |

| ⭐ \*\*Impact qualité\*\* | Une maison notée 10 se vend \*\*8,8× plus cher\*\* qu'une notée 2 |

| 🔥 \*\*Cheminée\*\* | +25 % de prix moyen avec cheminée |

| 🚗 \*\*Garage\*\* | +22 % de prix moyen avec garage |

| 📅 \*\*Évolution\*\* | Les maisons des années 2000+ valent \*\*2,8× plus\*\* que celles des années 1900 |
